# Hoja de ruta

Fases definidas en la especificación maestra. Cada fase empieza solo con **aprobación explícita** y termina con un informe de revisión.

| Fase | Contenido                                                                                                                                                                                                                            | Estado                                                |
| ---- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------- |
| 1    | **Fundamentos**: entorno, proyecto limpio, tecnologías, arquitectura, configuración, identidad visual, primera interfaz navegable del entrenador y del cliente, modelo conceptual de datos (incluida la biblioteca multidimensional) | Hecha; pendiente de tu revisión (`PHASE1_REPORT.md`)  |
| 2    | **Autenticación y usuarios**: registro e inicio de sesión, roles, entrenadores, clientes, permisos y aislamiento de datos (con base de datos y RLS)                                                                                  | Pendiente de aprobación (requiere decidir P-01, P-02) |
| 3    | **Clientes**: gestión, fichas individuales, pestañas, información y objetivos                                                                                                                                                        | Pendiente                                             |
| 4    | **Biblioteca**: modelo de datos completo, catálogo, etiquetas multidimensionales, patrones, variantes, progresiones y regresiones, filtros Y/O, buscador avanzado, favoritos                                                         | Pendiente                                             |
| 5    | **Evaluaciones**: registro de pruebas e intentos, historial, gráficos, comparaciones                                                                                                                                                 | Pendiente                                             |
| 6    | **Planificación**: planes, semanas, sesiones, programación de ejercicios, integración con la biblioteca                                                                                                                              | Pendiente                                             |
| 7    | **Portal del cliente**: entrenamiento diario protagonista, consulta de ejercicios, registro de ejecución, comunicación con el entrenador, progreso en un apartado independiente                                                      | Pendiente                                             |
| 8    | **Carga y volumen**: cálculos, seguimiento, resúmenes y análisis                                                                                                                                                                     | Pendiente                                             |
| 9    | **Readaptación e informes**: procesos, fases, criterios, informes                                                                                                                                                                    | Pendiente                                             |
| 10   | **Validación y despliegue**: seguridad, pruebas, rendimiento, accesibilidad, PWA y despliegue (solo tras autorización)                                                                                                               | Pendiente                                             |

Algunas pantallas de fases posteriores ya existen en la Fase 1 como **propuesta visual con datos ficticios** (por ejemplo, el portal del cliente o el buscador de la biblioteca). Su lógica de dominio está probada, pero no tienen persistencia ni edición. `PHASE1_REPORT.md` detalla qué funciona de verdad y qué no.
