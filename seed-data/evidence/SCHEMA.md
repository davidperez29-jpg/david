# Evidence seed format

One JSON file per topic: `{ "sources": [...], "findings": [...], "claims": [...] }`.

## sources[]

| field                                                                                                                      | type                                                                                | rule                                                                                                                                                                                                    |
| -------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| key                                                                                                                        | string                                                                              | unique, e.g. `schoenfeld2017_volume`                                                                                                                                                                    |
| pmid                                                                                                                       | string                                                                              | REQUIRED when indexed in PubMed; copied from the PubMed record                                                                                                                                          |
| doi                                                                                                                        | string \| null                                                                      | exactly as in PubMed record                                                                                                                                                                             |
| title, journal, volume, issue, pages                                                                                       | string                                                                              | exactly as PubMed                                                                                                                                                                                       |
| authors                                                                                                                    | string[]                                                                            | "Lastname AB" as in PubMed (corporate author allowed)                                                                                                                                                   |
| year                                                                                                                       | number                                                                              |                                                                                                                                                                                                         |
| studyDesign                                                                                                                | enum                                                                                | guideline, position_stand, consensus, umbrella_review, systematic_review, meta_analysis, rct, non_randomized_trial, cohort, cross_sectional, case_series, mechanistic, narrative_review, expert_opinion |
| populationSummary, ageRange, intervention, comparison, outcomesMeasured, resultsSummary, limitations, practicalApplication | string (Spanish)                                                                    | resultsSummary only states what the abstract says                                                                                                                                                       |
| sex                                                                                                                        | female \| male \| mixed \| unknown                                                  |                                                                                                                                                                                                         |
| trainingStatus                                                                                                             | untrained \| recreational \| trained \| highly_trained \| elite \| mixed \| unknown |                                                                                                                                                                                                         |
| sport                                                                                                                      | string \| null                                                                      |                                                                                                                                                                                                         |
| access                                                                                                                     | abstract_only \| full_text                                                          | what was actually read                                                                                                                                                                                  |

## findings[]

| field                                                                              | rule                                                                                                                                                                              |
| ---------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| key, source (source key)                                                           |                                                                                                                                                                                   |
| outcome                                                                            | slug from the outcomes catalogue                                                                                                                                                  |
| population                                                                         | slug from the populations catalogue                                                                                                                                               |
| intervention, comparator                                                           | Spanish                                                                                                                                                                           |
| effectMetric, effectValue, ciLow, ciHigh, nStudies, nParticipants, heterogeneityI2 | numbers ONLY if literally present in the abstract/full text read; else null                                                                                                       |
| quote                                                                              | VERBATIM fragment (≤ 300 chars) from the abstract that contains the result                                                                                                        |
| grading                                                                            | `{ design, riskOfBias, inconsistency, indirectness, imprecision, publicationBias }` — design = studyDesign; others: `no` \| `serious` (inconsistency may also be `contradictory`) |
| epistemicType                                                                      | `fact`                                                                                                                                                                            |

## claims[]

| field         | rule                                                                                            |
| ------------- | ----------------------------------------------------------------------------------------------- |
| key           | unique                                                                                          |
| statement     | Spanish, our wording, no causal language beyond the evidence, never "previene lesiones" as fact |
| scope         | method / variable / outcome concerned                                                           |
| epistemicType | `fact` (only if population matches the studies), `inference`, `hypothesis`                      |
| findings      | `[{ "finding": key, "role": "supports" \| "contradicts" \| "context" }]`                        |
| confidence    | high \| moderate \| low \| very_low                                                             |
| limitations   | Spanish                                                                                         |
| applicability | `{ "appliesTo": [population slugs], "notFor": [population slugs] }`                             |
